#  Loja de Beleza

Landing page de e-commerce para uma loja de maquiagem e produtos de beleza, com vitrine de produtos organizada por categoria.

##  Link do site:
> https://isabellyfranklin.github.io/Loja-de-Beleza/

##  Funcionalidades
- Vitrine de produtos em carrossel (Mais Vendidos, Lábios, Rosto, Olhos, Pincéis)
- Botão "Adicionar no Carrinho" em cada produto
- Exibição de preço com desconto (valor original riscado + valor promocional)
- Seção "Sobre nós" com destaques da marca (qualidade, variedade, confiança, novidades)
- Layout responsivo com header, banner de promoção e footer com redes sociais

##  Tecnologias utilizadas
- **HTML5** — estrutura semântica da página
- **CSS3** — estilização dos cards e do layout
- **JavaScript (Vanilla)** — lógica do carrossel, interações e manipulação do DOM
